# **App Name**: ZoneFlow HR

## Core Features:

- Employee Directory: Display employee information, including contact details, department, designation, and location.
- Location Segmentation: Group employees by Head Office, Zonal Office, or Labour Colony for targeted management.
- Time Off Management: Facilitate attendance input and leave request submissions. Use AI to make sure users can't take a negative leave balance. This system uses an LLM-powered tool.
- Salary Definition: Define the salary structure according to the worker's job, responsibilities and locations.
- Digital Filing Cabinet: Maintain employee digital records, track contract expiries and store important data like medical and insurance information.
- Access control: Restrict access based on user roles, such as Admin, HR Manager, and Employee.
- Reporting dashboard: Provide a summary of active and inactive employees according to location and time off taken.

## Style Guidelines:

- Primary color: Light, desaturated blue (#ADD8E6) to convey trustworthiness.
- Background color: Pale blue (#F0F8FF), almost white.
- Accent color: Soft yellow (#FAFAD2) to highlight interactive elements and important information.
- Body and headline font: 'PT Sans' (sans-serif) for a modern but warm, friendly, accessible look. This font is suitable for both headlines and body text.
- Use simple, professional icons to represent HR functions and data categories.
- Employ a clear, structured layout that aids navigation, data entry, and report viewing.
- Use subtle transitions and feedback animations to enhance user interaction.
